6axi_arbiter.sv — AXI4 合并器

纯组合逻辑（除 1 个 1-bit 寄存器外），将 IFU 和 LSU 的 AXI4 端口合并为一个 Master 端口。

6.1 设计决策

通道策略原因
AR（读地址）组合 MUX，LSU 优先流水线中 IFU 被 lsu_busy 阻塞，不会同时发请求
R（读数据）sel_lsu_ar 路由回请求方1-bit 寄存器记录谁发了 AR
AW/W/B（写）直通仅 LSU 使用，无需仲裁

6.2 读通道仲裁

📄 axi_arbiter.sv · 第 110-144 行
// AR 通道选择寄存器
logic sel_lsu_ar;  // 1 = LSU 获得 AR 通道
always_ff @(posedge clk or negedge rst_n) begin
    if (!rst_n) sel_lsu_ar <= 1'b0;
    else if (m_arvalid && m_arready)  sel_lsu_ar <= 1'b0;
    else if (lsu_arvalid && !ifu_arvalid) sel_lsu_ar <= 1'b1;
end

// AR MUX
assign m_arvalid = lsu_arvalid | ifu_arvalid;
assign m_araddr  = lsu_arvalid ? lsu_araddr : ifu_araddr;

// R 路由
assign lsu_rvalid = m_rvalid && sel_lsu_ar;
assign ifu_rvalid = m_rvalid && !sel_lsu_ar;

6.3 写通道直通

// 仅 LSU 使用，无需仲裁
assign m_awvalid = lsu_awvalid;
assign m_awaddr  = lsu_awaddr;
// ... 所有 AW/W 信号直通
assign lsu_bvalid = m_bvalid;  // B 回复直通

8sim_top.sv — 仿真环境

实例化 core + arbiter + AXI4 Slave 存储器模型。Slave 内部调用 DPI-C（paddr_read/paddr_write），并注入 LFSR 随机延迟。

8.1 架构

core ──AXI4──► axi_arbiter ──AXI4──► AXI4 Slave 存储器模型
                                      ├── 读状态机 (RD_IDLE→DELAY→RESP)
                                      ├── 写状态机 (WR_IDLE→DELAY→RESP)
                                      ├── LFSR 随机延迟 (1~4 周期)
                                      └── DPI-C (paddr_read/write)

8.2 Slave 读状态机

RD_IDLE ──arvalid&&arready──► RD_DELAY ──cnt>=target──► RD_RESP ──rvalid&&rready──► RD_IDLE
   │                            │                         │
   │ 握手时调用                  │ LFSR 延迟               │ 输出 rdata
   │ paddr_read(araddr)         │ 1~4 周期                │ rresp=OKAY
